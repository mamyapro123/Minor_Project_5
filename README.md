# Excel Minor Project

## Overview

This repository contains the completed **Excel Minor Project** workbook.

The project is designed as a practical spreadsheet-analysis exercise. It uses Excel to organize the provided project data, perform the required calculations, and present the answers for the questions included in the workbook.

## Project File

- **Completed workbook:** `13548653-Excel_Minor_Project_COMPLETED.xlsx`

## What the Workbook Contains

The workbook includes the project questions and their corresponding answer sections. The required answer boxes have been filled using the data and instructions provided in the original workbook.

The project covers **Question 1 through Question 5**, with the answers entered directly into the relevant cells so the workbook can be reviewed or submitted as a complete project.

## Main Objectives

The main objectives of this project are to:

- Work with structured data in Microsoft Excel.
- Understand the information provided in a spreadsheet.
- Apply appropriate calculations and formulas.
- Analyze the given data according to each question.
- Present results clearly in the designated answer boxes.
- Practice spreadsheet-based problem solving and data analysis.

## Tools & Technologies

- **Microsoft Excel**
- **Excel formulas and calculations**
- **Spreadsheet-based data analysis**
- **Data interpretation and reporting**

## Project Workflow

The general workflow followed for the project was:

1. Open and inspect the original Excel workbook.
2. Understand the dataset and instructions associated with each question.
3. Identify the required calculation or analysis for each answer box.
4. Perform the required analysis using the workbook data.
5. Enter the answers into the appropriate cells.
6. Review the completed workbook for consistency and readability.
